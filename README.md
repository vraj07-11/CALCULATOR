# Calculator App 🧮

A sleek and interactive web calculator built with HTML, CSS, and JavaScript capable of handling everyday arithmetic calculations smoothly.

### Features
- **Smooth Operations:** Performs basic math operations with a clean, responsive layout.
- **Instant Display:** Real-time calculation feedback as you click.
- **Mobile Friendly:** Designed to work effortlessly across phones, tablets, and desktops.
